# Go companion

This module will own PersonaStack machine credentials, enrollment and gateway transport, Cua integration, local CLI setup, and bounded filesystem and process execution.

`cmd/personastack-companion` runs the Go companion as a newline-delimited JSON process. It accepts a single production or LAN app origin argument. The Desktop Control bridge supports `sync`, `state`, and `prepare`. `prepare` reports that the Linux runtime is unavailable, so it does not consume an enrollment ticket or claim Desktop Control readiness. The local-session bridge supports its versioned state, harness selection, prepare, and configure commands through the Linux CLI probe and plugin installer. Machine credentials stay in the Linux Secret Service adapter and never appear in process arguments, bridge logs, or replies. `npm start` builds it into `companion/bin` and Electron starts it lazily for a request from the registered main frame at the configured origin and current document generation. Packaged app bundling is not configured yet.

Host-independent packages also prepare, claim, heartbeat, and report session readiness through the producer-owned API client. Local-session setup validates the producer-owned bundle, checks the selected CLI and writes only PersonaStack-owned plugin files. `internal/cuainstaller` downloads the Cua Driver 0.29.1 Linux x86_64 candidate from `support-profile.json`, checks its published archive checksum and extracted file hashes, and preserves the Cua MIT and Node runtime MPL-2.0 notices. It installs under the user's data directory. `internal/desktopgateway` and `internal/cuamcp` implement bounded transports. `internal/desktopexecutor` implements the reviewed Cua dispatch families, bounded screenshot results, exclusive lease, and revocation fences. `internal/desktopfiles` and `internal/desktopprocess` provide bounded standalone Linux operation managers. They are not yet scoped or dispatched by the executor. The companion command does not yet wire these pieces together or start Cua. Native readiness stays false. The optional Hyprland input plugin is not installed. Tests use fake APIs, commands, sockets, download responses, an MCP child process, and temporary files. They do not prove real API, CLI plugin-manager, Secret Service, Cua, or Omarchy behavior. There is no plaintext credential fallback. Keep API and gateway wire contracts imported from their producer-owned Go packages.

`go.mod` requires Go 1.27.0 and suggests Go 1.27.1. Go may use a newer installed toolchain, so future companion validation must explicitly select the pinned toolchain with `GOTOOLCHAIN=go1.27.1` rather than treating the `toolchain` directive as an upper bound.
