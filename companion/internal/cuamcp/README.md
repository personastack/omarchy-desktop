# cuamcp

`cuamcp` owns one Linux `cua-driver mcp` stdio process. It uses bounded newline-delimited JSON-RPC, validates response IDs and MCP result envelopes, validates the catalog against the macOS app's reviewed 33-tool allowlist, serializes calls, and disables telemetry and update checks in the child environment. Timed-out writes terminate the owned child so a blocked pipe cannot hold shutdown. Setup can request Cua's Linux `health_report` or its read-only `check_permissions` result. `ReadyFor("0.29.1")` means the schema-version-1 diagnostic report matches that selected driver version, reports `overall: ok`, and passes `binary_version`, `platform_supported`, `session_active`, `ax_capability`, and `screen_capture_capability`. These checks do not establish an unlocked interactive desktop or prove that a screenshot was captured. Linux capture capability can use compositor protocols beyond X11. Neither setup method is available through remote Desktop Control operations. The executable path must come from the integrity-checked Cua installation owner. This package does not install Cua or claim that a tool works on Hyprland/Omarchy.
