## Objective and completion rule

An Omarchy user can install PersonaStack, sign in, use every hosted desktop surface and native pop-out, configure a local persona CLI, and authorize personas to control that same logged-in computer with the functionality of the macOS app.

Full parity is the completion gate. Every baseline behavior must have an implemented Linux equivalent and appropriate evidence. An unavailable Cua tool, weakened bridge boundary, missing window action, or unverified native lifecycle leaves the plan incomplete. Linux uses its own application identities and OS affordances. Safari, Keychain, AppKit, and the Dock are not literal Linux dependencies.

Baseline: `macos-desktop` source revision `400069f7fb0ddd475907f12a52acd7f7f21c5b5b`, its current `SPEC.md`, native tests, and current producer contracts. The inspected working spec also contains an installer clarification. Reconcile intentional baseline changes at implementation start. Do not silently expand scope to future Mac features.

## Selected design

Use **Electron plus one Go companion in one repository and one application lifetime**.

- Electron owns windows, the persistent hosted browser session, notifications, tray, navigation and the finite native bridge. Reuse the five existing bridge contracts: `personastackConcern`, `personastackChat`, `personastackStack`, `personastackLocalSession`, and `personastackDesktopControl`.
- Go owns protected machine credentials, enrollment, the outbound gateway connection, local CLI configuration, the Cua lifecycle and local executors. Import the API-owned Go client/contracts. Do not hand-copy gateway DTOs.
- Connect the two owned processes with bounded typed messages over inherited pipes. No local HTTP server, detached service, browser-accessible socket, generic command bridge or second authentication store.
- Keep remote renderers sandboxed with context isolation and Node disabled. Native admission checks registered window role, `senderFrame === mainFrame`, exact scheme/host/effective port, finite DTO and current navigation generation. Reject missing/stale frames. Recheck deferred results and commits after navigation or cancellation.
- Keep the current hosted routes, streams, authorization and resource renderers. Native code handles presentation. Only authorized Desktop Control requests reach the executor.
- Use one persistent browser partition per environment. Retain the same authenticated main web contents as the hidden concern receiver and restore it on Open. A single-instance lock prevents duplicate relays.
- Use Linux Secret Service for protected native credential custody. Missing/locked storage is actionable and fails closed. Never fall back to a plaintext token file. Certify a concrete provider on the supported Omarchy profile.
- Use a narrow Hyprland adapter only where Electron lacks required native window behavior. Address app-owned windows with native identifiers and process identity. Webpage titles and supplied shell text are not window authority.
- Preserve one exclusive PersonaStack lease even though Cua can supply an independent synthetic cursor. Do not add concurrent agent sessions.

### Choice and rejected complexity

| Option | Assessment |
| --- | --- |
| Electron + Go | Selected. Native IPC exposes originating frame identity. Go reuses producer-owned contracts and fits the executor. Costs are Chromium maintenance, package size and one small private process protocol. |
| GTK/WebKitGTK + Go | Smaller shell. Standard script-message-with-reply callbacks do not supply the native frame identity needed by the existing bridge contract. A custom web-process extension adds security-sensitive machinery. |
| Tauri + Go | Adds Rust while retaining Go for integration/runtime work. Linux WebKit frame admission still needs proof or added machinery. No simplifying gain for this scope. |

Do not rewrite the Mac app, build a shared native-runtime repository, or add a second frontend. The new runtime has no product datastore to migrate. Package rollback must preserve browser data and keyring items without claiming that an older runtime can speak an incompatible server protocol.
